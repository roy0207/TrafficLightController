Traffic Light System - How to Run

LOCAL WINDOWS / LOCAL MACHINE
-----------------------------
If you are running the project locally on your own computer and have already built
the Python extension module, run:

    python app.py

This should open the GUI window.

CODESPACES / GITHUB
-------------------
Codespaces is a headless environment, so Tkinter windows do not open there.
In Codespaces, app.py will automatically run a terminal-based backend demo instead.

First-time build in Codespaces:
    cd /workspaces/trafficLightSystem/TrafficLightSys
    mkdir build
    cd build
    cmake .. -Dpybind11_DIR=$(python -m pybind11 --cmakedir)
    cmake --build .
    cd ..
    python app.py

Clean rebuild in Codespaces:
    cd /workspaces/trafficLightSystem/TrafficLightSys
    rm -rf build
    mkdir build
    cd build
    cmake .. -Dpybind11_DIR=$(python -m pybind11 --cmakedir)
    cmake --build .
    cd ..
    python app.py

Quick rebuild in Codespaces:
    cd /workspaces/trafficLightSystem/TrafficLightSys/build
    cmake --build .
    cd ..
    python app.py

NOTES
-----
1. The build folder is created by CMake.
2. On Linux/Codespaces, the compiled Python module will be a .so file.
3. On Windows, the compiled Python module will be a .pyd file.
4. The app uses:
      - C++ for the simulation/backend
      - pybind11 for Python bindings
      - Python Tkinter for the GUI
5. Codespaces is mainly for building/testing the backend.
6. Local desktop machines are used for the actual GUI window.
